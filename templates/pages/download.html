Download Soundfolk

$version_line Free, for 64-bit Linux, Windows and macOS. Every package is built from the public source by GitHub, and signed by it.

Debian, Ubuntu, Linux Mint

Ubuntu 22.04 or later, Debian 12 or later, and their derivatives.

Download the .deb

Open the file to install it, or from a terminal:

sudo apt install ./$deb_name

Other Linux distributions

Any distribution with glibc 2.35 or later.

Download the AppImage 
chmod +x $appimage_name
./$appimage_name

It needs FUSE 2 (libfuse2, or libfuse2t64 on Ubuntu 24.04); without it, add --appimage-extract-and-run.

Windows

Windows 10 or later, 64-bit. No administrator rights needed.

Download the installer

The installer is not code-signed yet, so SmartScreen warns before running it: click More info, then Run anyway. It downloads Microsoft WebView2 if Windows lacks it.

macOS

macOS 10.13 or later, Apple silicon and Intel.

Download the disk image

Drag Soundfolk into Applications. The app is not notarized by Apple yet: the first time, macOS refuses to open it. Go to System Settings › Privacy & Security and click Open Anyway.

Updates

Soundfolk checks once a day whether a new version is out, and says so in its settings. It never downloads or installs anything by itself: you update the way you installed it. Updates through Soundfolk’s own APT repository, with the system’s other updates, are coming for the .deb.

Want the latest changes? A build of the main branch is published every night as the nightly pre-release. It may break.

Checking a package

Every package carries a GitHub attestation: proof that it was built by the project’s CI from its public source. With the GitHub CLI: 

gh attestation verify $deb_name -R getsoundfolk/soundfolk

Building from source

Soundfolk is a Tauri 2 app: a Rust audio engine and a Svelte interface. You need Rust and Node.js; on Linux, the WebKitGTK and ALSA development packages. 

git clone https://github.com/getsoundfolk/soundfolk
cd soundfolk
npm install
npm run tauri dev

The README lists the packages for each system.
